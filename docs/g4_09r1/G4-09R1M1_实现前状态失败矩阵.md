## State matrix

| 输入状态 | 机制结果 | 不变量 |
|---|---|---|
| settings 文件缺失 | 返回已校验默认值 `deepseek_v4_pro / 256k / high` | 不创建或修改 Game、Source、SQLite |
| settings 文件合法 | 精确恢复 `profile_id / context_limit / reasoning_request` | 不读取任意 endpoint/model id |
| settings 文件 malformed / unknown | 返回可恢复的结构化 `invalid_persisted_settings` | 未校验值不进入 Provider |

| Provider request 开始 | 冻结 endpoint/model/context/reasoning/credential-name snapshot | active request 中途不重读 settings |
| settings 后续改变 | 只影响下一次 request snapshot | 不改变当前 request、Game/Source/SQLite |

## Failure matrix

| 失败 | 对外结果 | 网络 / durable 副作用 |
|---|---|---|
| selected Provider key 缺失 | `missing_key`，指出变量名而不含值 | 零网络；不 fallback |
| 只存在另一 Provider key | 仍为 selected Provider `missing_key` | 零网络；不跨 Provider |
| malformed SSE JSON | 恰好一次 `failed(malformed_stream)` | reasoning/partial draft 不 accepted |
| reasoning-only delta | 忽略，不发 `text_delta` | 不进入 GM narrative / Conversation |
| HTTP 非 2xx | bounded、sanitized `http_<status>` | key 不进入 error/result/log |
| active 时第二次 start | `ERR_BUSY` | 原 active snapshot/request 不变 |
| cancel | 恰好一次 `cancelled` | 不迟发 completed/failed |
| persisted/request settings 非法 | 结构化 settings failure | 任意 profile 不进入 Provider；零网络 |

## Layer ownership

- `运行时设置/L0_公理层`：closed catalog、组合校验、endpoint/model/reasoning/context 派生。
- `运行时设置/L1_器件层`：application-local JSON 的 fail-safe 原子存储。
- `运行时设置/L2_流程层`：default/load/save、credential availability 与 request snapshot 编排。
- `运行时设置/L3_外交层`：供 Provider、Context 与未来 Settings UI 使用的唯一公开边界。
- `provider/L1_器件层`：OpenAI-compatible SSE 内容解析；隔离 reasoning/thinking chunk。
- `provider/L2_流程层`：单请求 streaming 生命周期、busy/cancel/exactly-one terminal。
- `provider/L3_外交层`：从运行时设置 L3 冻结 profile 并绑定 selected credential；所有产品调用点只依赖此 seam。
