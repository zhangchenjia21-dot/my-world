- L3 新增 `validated_default_settings() -> Dictionary`，返回冻结默认值的防御性副本；

- 未修改 `src/应用壳.gd`、UI、Provider、Source、Final Create、Persistence、Public d20。

职责归层：

```text

```

## 2. Exact L3 default API

```gdscript
validated_default_settings() -> Dictionary
```

精确返回：

```json
{
  "profile_id": "deepseek_v4_pro",
  "context_limit": "256k",
  "reasoning_request": "high"
}
```

测试修改第一次返回的 Dictionary 后再次调用，仍得到精确默认值，证明调用方不能修改冻结默认。使用 task-owned settings path 调用时不创建设置文件，也不读取或返回 credential value。

## 3. Incompatible-candidate projection

输入：

```json
{
  "profile_id": "kimi_k27",
  "context_limit": "1m",
  "reasoning_request": "high"
}
```

结果保持：

```text
success = false
status = incompatible_context_limit
```

同时返回：

```json
{
  "candidate": {
    "profile_id": "kimi_k27",
    "display_name": "Kimi K2.7",
    "provider_id": "kimi",
    "context_limit": "1m",
    "allowed_context_limits": ["256k"],
    "reasoning_requested": "high",
    "reasoning_effective": null,
    "graded_reasoning": false,
    "fixed_thinking": true,
    "credential_configured": true
  }
}
```

`credential_configured` 是当前测试环境的 selected-provider boolean，不是固定产品值。unknown profile 与 malformed settings 继续失败且不返回 partial identity。
