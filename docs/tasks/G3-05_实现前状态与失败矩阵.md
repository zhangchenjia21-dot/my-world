# G3-05 实现前状态与失败矩阵

本矩阵在 schema v4 与 Recovery 路径编码前冻结 Load/Recover 语义。它只覆盖最近一次高影响进度切换的内部恢复能力与现有 immutable Timeline DAG 分支正确性；不建立 Recovery/Timeline history browser、branch picker、任意 Turn rewind、retention/cleanup、backup/corruption platform 或 G3-06。

## 1. Ownership 与原子边界

| 职责 | Owner / 层级 | 冻结不变量 |
|---|---|---|
| accepted Turn 的合法性、顺序、non-mutating validation、in-memory replacement | Conversation Domain | Persistence 不复制 Conversation 业务规则；streaming/cancelled/failed partial 永不成为恢复材料 |
| schema v4、immutable Recovery representation、latest monotonic order、protected progress switch transaction | Persistence `L2_流程层` | Recovery 引用同 Game immutable Timeline anchor 并携带 accepted Conversation；capture 与 switch 全成或全败 |
| latest Recovery read model、protected Load/Recover API | Persistence `L3_外交层` | 不泄露 SQLite row/sequence/node 工程细节；`recovery_id` 是业务 identity，sequence 只负责 durable ordering |
| active-generation gate、Domain 预检、COMMIT 后 memory apply、`reopen_required` | Current Game Runtime | durable COMMIT 先于 Runtime/Conversation/UI 切换；post-COMMIT memory failure 禁止继续运行 |
| named Save 与 latest Recovery 的分离展示、明确确认、Narrative full redraw | Application Shell / UI | UI 不保存第二份 truth，不列历史、不展示 branch/node/recovery row 调试信息 |
| Provider request material | Context Assembly | 只从 switch 后 current accepted truth 重建；recent 12；current player exactly once/last；不读取 stored Prompt/Context |

受保护 Load 固定为：Domain 预检 immutable Save Conversation → `BEGIN IMMEDIATE` → transaction 内重新解析并 exact 比对 Save → 读取 coherent current head/World/Conversation → exact no-op 则无写入结束 → 插入 displaced-current Recovery → 恢复 target World → 更新 active head → 替换 durable Conversation → `COMMIT`。

受保护 Recover 固定为：Domain 预检 latest Recovery Conversation → `BEGIN IMMEDIATE` → transaction 内按 monotonic sequence 重新解析并 exact 比对 target → 读取 coherent current triple → exact no-op 则无写入结束 → 插入 current reciprocal Recovery → 恢复 target World/head/Conversation → `COMMIT`。

任一步在 COMMIT 前失败都 rollback，current triple 与原 latest useful Recovery 不变且没有 orphan row。COMMIT 后才更新 Runtime head/World、替换 in-memory Conversation、发出一次 full-redraw 信号并在下一次请求重建 Context。

## 2. Load old Save with automatic Recovery

表中 `H/W/C` 表示 durable active head / current World materialization / current accepted Conversation；`Rlatest` 表示按 durable monotonic sequence 选出的 latest useful Recovery。

| 场景 | Durable H/W/C | In-memory Conversation | Rlatest 与历史记录 | Context / 玩家结果 | rollback、retry 与阻断风险 |
|---|---|---|---|---|---|
| current 与 target Save 的 head + accepted Conversation exact 相同 | 全部不写 | 不替换；保持 current | Recovery count、identity、sequence、Rlatest 全不变；Save/Timeline 不变 | 返回稳定 `already_current`，提示已是当前进度；Context 不变 | 真 no-op；无 half-switch、orphan、future leak、latest 覆盖 |
| Conversation-only future | 原子从同一 head 的 `A+B` 切为 Save 的 `A`；World/head 数值不变 | COMMIT 后 exact 替换为 `A` 并 full redraw | 新 R 指向同一 head、保存 exact `A+B`；older R、Save、Timeline 全保留；R 成为 latest | 下一请求只含 `A`；提示已读取且可恢复读取前进度 | 失败则 `A+B` 全保持且无新 R；可原操作重试 |
| later World head + Conversation future | 原子从 `H2/W2/C2` 切为 `H1/W1/C1` | COMMIT 后 exact `C1` | 新 R→`H2/C2`；H2 immutable 保留；Save/older R/Timeline 不删除 | Context 只从 `C1` 与 current World projection 重建；玩家获得恢复入口 | 无 mixed H/W/C；失败可重试 |
| latest Turn 已成功 Regenerate | Load 到旧 Save；被替换 current durable C 中是 regenerated GM | COMMIT 后为 Save C | R exact 捕获 regenerated accepted GM；不含旧 GM/attempt draft | Recover 可精确找回 regenerated GM | partial/failed attempt 不可见；无 future leak |
| latest Turn 已成功 Corrected | Load 到旧 Save；被替换 C 是 corrected player+GM | COMMIT 后为 Save C | R exact 捕获 corrected pair | Recover 可精确找回 correction 后 truth | 不恢复 superseded pair；失败无 R |
| current 有 >12 accepted Turns | Save target 全量恢复，current 全量被捕获 | memory 保存/替换均为全量 accepted | R 保存全量 current C，不截断；历史不变 | Context 仍仅 recent 12；不是 Recovery 截断 | 无 starved recovery；current user 仍只出现一次且最后 |
| active Provider generation | durable current 不变 | streaming attempt 继续或由玩家先明确取消 | 无 Recovery/Save/Timeline 变化 | Load control disabled；提示等待或取消 | 不允许 silent switch beneath request；partial 不入 R |
| missing/corrupt Save target | current 不变 | 不变 | 无变化 | fail-loud，可刷新/重试；不选择其他 Save | 无 fallback、orphan 或 latest 误选 |
| missing/corrupt target Timeline anchor/snapshot | current 不变 | 不变 | 无变化；坏 Save 不被“修复” | storage/integrity failure，玩家 current 保持 | transaction rollback；不猜 World、不 fresh fallback |
| invalid target Conversation recovery material | Domain 预检前无写入，current 不变 | validation non-mutating，live C 不变 | 无变化 | `invalid_conversation`，不进入切换 | Persistence 不自行宽松解析；无 half-switch |
| Recovery INSERT failure | current H/W/C 不变 | 不变 | insert rollback；Rlatest 与 count 不变 | fail-loud，可重试 | 无 orphan |
| World update failure after Recovery INSERT | transaction rollback，旧 H/W/C 全保持 | 不变 | 新 R rollback；历史与 latest 不变 | 读取失败，当前进度没有改变 | 无 orphan/half-switch |
| head update failure after World update | transaction rollback，旧 H/W/C 全保持 | 不变 | 新 R rollback | 同上 | 无 World/head split |
| Conversation update failure after head update | transaction rollback，旧 H/W/C 全保持 | 不变 | 新 R rollback | 同上 | 无 head/Conversation split、无 future leak |
| COMMIT failure | transaction rollback 或返回明确 storage failure；不得宣告 success | 不替换 | 新 R 不存在；latest 不变 | fail-loud，可重试 | 无成功假象或 orphan |
| COMMIT success 后进程死于 memory/UI apply 前 | target H/W/C 与 displaced-current R 已完整 durable | 进程 memory 不可信且不得继续；重开 exact rehydrate target | 新 R 可从 DB 重建为 latest；历史全保留 | reopen 显示 target current + Recovery 可用 | 无 shutdown flush 依赖；旧 memory 不得继续发请求 |

## 3. Recover Previous Progress

| 场景 | Durable H/W/C | In-memory Conversation | Rlatest 与历史记录 | Context / 玩家结果 | rollback、retry 与阻断风险 |
|---|---|---|---|---|---|
| 不存在 Recovery | current 不变 | 不变 | 空集保持 | UI 不显示/禁用恢复入口；API `not_found` | 不创建占位 R，不 fallback 到 Save/Timeline |
| latest Recovery target 与 current exact 相同 | 全部不写 | 不替换 | count、Rlatest identity/sequence 全不变 | `already_current`；说明已是该进度 | 无 reciprocal spam 或错误 latest |
| Load 后 valid latest R | 原子从 restored Save H/W/C 回到 pre-Load H/W/C | COMMIT 后 exact 替换并 full redraw | 先新增 reciprocal R 保存被替换 current，再切换；新 R 成 latest；目标旧 R 不删除 | Context 只从 recovered truth 重建；提示当前进度已恢复且刚才进度仍受保护 | 失败全 rollback；无 consume/delete |
| restored Save 上继续新 Conversation 后 Recover | 原子回到旧 future；被替换 branch 的 head 可相同但 C 更新 | exact old-future C | reciprocal R 保存 branch C；older R/Save/Timeline 保留 | branch-only marker 从 accepted C 与 Context 消失；可再次 Recover 返回 branch | 无 Conversation 混合或 future leak |
| restored old node 上产生新 World branch 后 Recover | 从 H3/W3/C3 原子回 H2/W2/C2 | exact C2 | reciprocal R→H3/C3；H1 的 H2/H3 children 均 immutable 保留；无 branch registry | Context 只含 C2；玩家无需知道 DAG | 无 node delete/rewrite、无 half-switch |
| invalid/missing Recovery Timeline anchor/snapshot | current 不变 | 不变 | Recovery row保留供诊断；不新增 reciprocal | fail-loud，不偷偷选 older R | 无错误 latest fallback |
| invalid Recovery Conversation material | Domain 预检失败，current 不变 | live C 不变 | 无新增 reciprocal，Rlatest 不变 | `invalid_conversation` | 无 Persistence-owned semantic repair |
| reciprocal INSERT 后任一步 switch 失败 | transaction rollback，旧 H/W/C 全保持 | 不变 | reciprocal 不存在；原 Rlatest 不变 | fail-loud，可重试 | 无 orphan、half-switch 或 latest 漂移 |
| COMMIT failure | current 与 reciprocal 一起 rollback | 不变 | count/latest 不变 | fail-loud | 不宣告恢复成功 |
| COMMIT success 后进程死于 memory/UI apply 前 | target H/W/C + reciprocal R durable | 进程停止；重开 exact target | reciprocal 是 durable latest，原 target/history 保留 | reopen 后可继续/再次 Recover | 无旧 memory 对新 DB 继续 |
| normal reopen after Recover | recovered H/W/C exact | startup rehydrate exact | latest reciprocal 从 DB 读取；全部历史保留 | UI 重建 availability，Context 下一请求重建 | 不依赖 previous-process label/cache |
| 同一秒快速 Load/Recover | 每次 transaction 的目标 exact | 每次仅在 COMMIT 后替换 | `created_at` 可相同；严格按 AUTOINCREMENT sequence 选择实际最后插入 R | UI/API 始终指向最近被替换 current | 禁止按 timestamp/recovery_id 猜 latest |

## 4. Symmetric Context、Conversation 与 Timeline 验证矩阵

| 证明链 | Durable / historical 预期 | Context / Player 预期 | Blocking failure |
|---|---|---|---|
| `S1 → Future A(RECOVERED_FUTURE_MARKER_A) → Load S1 → Branch B(DISPLACED_BRANCH_MARKER_B) → Recover A` | current exact A；reciprocal R exact B；S1 与所有 R/Timeline 保留 | A marker 可按历史位置出现；B marker 在 accepted C 与 Provider messages 完全不存在；recent 12；current player exactly once/last；无 raw World JSON | 任一 B marker 泄漏、A 不 exact、Prompt/Context 成为 durable truth |
| recovery 后 latest Regenerate | 同一 logical Turn 的 regenerated candidate 先 COMMIT 再 Domain accept | Context 排除被替换 assistant，成功后 only new accepted GM | identity 改变、旧 GM 混入、failure/partial 被捕获 |
| successful Regenerate → Load old Save → Recover | R/Recover exact round-trip regenerated accepted GM | full redraw 只显示 regenerated GM | 恢复 superseded GM 或 draft |
| successful Correction → Load old Save → Recover | R/Recover exact round-trip corrected player+GM | full redraw/Context 只含 corrected pair | 恢复 superseded pair |
| cancelled/failed/streaming attempt 后 stable Load | durable current C 不含 partial，R 只捕获 durable accepted C | recovered Context 不含 partial marker | UI transcript/draft 被当 truth |
| `H0→H1→H2；Save@H1；Load H1；mutation→H3` | H2.parent=H1、H3.parent=H1，二者 snapshot immutable，current=H3；Recovery 可回 H2 | UI 不展示 node/branch graph | 增 branch table、rewrite/delete H2、全局 sequence 重排 |

## 5. Schema v3→v4 与 failure matrix

| 场景 | 预期 durable 结果 | 失败语义 |
|---|---|---|
| real v3 open | additive 创建 `recovery_checkpoints` 与 latest-order index，version=4；existing Game/head/World/Conversation/Save/Timeline exact；Recovery initially empty | 无 data rewrite、无 duplicate World storage |
| fresh DB | v1 core + v2 Conversation + v3 Save + v4 Recovery 在同一初始化 transaction 成立 | 只在完整 COMMIT 后 ready |
| intentional mid-migration failure | 整体 rollback 到 usable v3；version 仍 3；Recovery table/index 不得 partial 留存 | startup fail-loud；修复后可重试，不 fresh fallback |
| same-second insert | `recovery_sequence INTEGER PRIMARY KEY AUTOINCREMENT` 单调且唯一；`recovery_id` stable identity | latest 只 `ORDER BY recovery_sequence DESC`，不依赖 wall-clock |
| immutable retention | Load/Recover 仅 INSERT Recovery，不 UPDATE/DELETE existing Recovery | 无 cleanup/retention/history manager |

## 6. 实现与验收约束

- `recovery_checkpoints` 只存 stable `recovery_id`、Game、Timeline anchor、accepted Conversation recovery material、reason、created_at 与 durable sequence；不复制 World snapshot，不混入 `save_points`。
- `already_current` 是 successful、non-committed、non-mutating result；Runtime/UI 不把它误报为新恢复。
- UI 只展示一个 latest useful Recovery affordance 与明确 confirmation，说明当前进度会切换且也会被保护；active generation 时 Load/Recover 一起禁用。
- Recover/Load 成功仅发出一次 Conversation projection full redraw；失败不 patch、不清空 Narrative。
- destructive/failure/crash fixtures 只可位于绝对路径校验后的 `build/g3_05_*`；不得触碰 unknown `user://` player DB。
- 不持久化 Context/Prompt/Provider messages，不向 Prompt 倾倒 opaque World JSON，不添加 `max_tokens` 或 Narrative 长度限制。
- 本矩阵不授权 G3-06、single-instance/stale-session、backup/corruption、Timeline browser、branch picker、arbitrary Turn rewind、Save manager、G4/G5/G7。
