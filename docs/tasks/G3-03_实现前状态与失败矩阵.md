# G3-03 实现前状态与失败矩阵

本矩阵在 production schema v2 与 runtime composition 编码前冻结 reopen/resume 语义。它只描述 current Game continuity，不建立 Save/Load/Restore、多 Game picker、historical Conversation 或 G5 entity schema。

## 1. 职责与分层

| 职责 | 归属 | 理由 |
|---|---|---|
| accepted Turn 顺序、replacement、rehydration、completion candidate | Conversation Domain | 继续由既有语义 owner 判断 new/regenerate/correction，不让 SQLite 复制规则 |
| accepted Conversation JSON representation、schema v2 migration、transaction | Persistence `L2_流程层` | 只拥有 durable representation、migration 与 I/O 失败传播 |
| Conversation read/write 与 Game identity query | Persistence `L3_外交层` | 对 runtime 暴露稳定 DTO，不泄露 SQLite row/connection |
| current DB path、first-run/open、one-current-Game、persist-before-accept | `src/runtime/` composition owner | 应用外围组合 Domain 与 Persistence L3，不塞进 UI 或四层内部 |
| restored projection、玩家输入与 Provider lifecycle | Narrative UI | 只渲染 Domain projection、派发意图，不打开 SQLite、不拥有第二 history |
| product startup/close wiring | Application Shell / Bootstrap | 集中生产路径与资源生命周期；script tests 使用显式隔离 runtime |

依赖方向保持 `Persistence L3 → L2 → L1 → L0`。Runtime 只调用 Persistence L3 与 Conversation 公开 seam；UI 只绑定 Runtime/Conversation，不直连 Persistence 内层。

## 2. State / Failure Matrix

| 场景 | Durable Game / World / head | Durable accepted Conversation | Reopen 后 Domain / Context | 返回或玩家可见结果 | 可创建新 Game | Silent fallback / partial accepted truth |
|---|---|---|---|---|---|---|
| first run：DB 不存在 | 生成一次 stable `game_id/root_id`，`{}`/root 原子建立 | 建立空 current materialization | 0 Turns；Context 仅 system，后续 attempt 正常追加 | `ready/created` | 是，仅此 genuine absence | 无 |
| normal accepted new Turn | Game/World/head 不变 | candidate append 后先 COMMIT | COMMIT 后 Domain accept；Context 含新 pair | success | 否 | 无；persist-before-accept |
| completed latest Regenerate | 不变 | candidate 在同一逻辑位置替换 GM | durable 成功后 Domain 同 Turn 替换；Turn count 不变 | success | 否 | 旧 GM 在 COMMIT 前保持 |
| completed latest Correction | 不变 | candidate 同位置替换 player+GM | durable 成功后 Domain 原子替换；无 duplicate Turn | success | 否 | 旧 pair 在 COMMIT 前保持 |
| Conversation write 在 COMMIT 前失败 | 不变 | 保持旧 materialization | Domain 不 accept candidate；attempt `FAILED/persistence_failure`，Context 仍来自旧 accepted truth | retryable persistence error | 否 | 无 partial accepted truth |
| graceful exit | 保持最后已提交 current truth | 不依赖退出时 flush；已 accepted 均已 durable | active non-accepted attempt abandon；连接关闭 | normal exit | 否 | streaming draft 不被补写 |
| 新 OS process reopen | exact same identity/World/head | exact text/order | 重新建立 `turn_index=0..N-1`，无 generating state；Context 重新组装 | `ready/resumed` | 否 | 不读取 stored prompt |
| reopen：0 accepted Turns | exact same identity/World/head | `[]` | empty Conversation；Context 仅 system/current attempt | ready | 否 | 无 |
| reopen：>12 accepted Turns | exact same identity/World/head | 全量 accepted truth | Domain 全量恢复；Context 仅 recent 12 complete pairs + current | ready | 否 | 不截断 durable history |
| cancelled/failed/streaming-only attempt 后 reopen | 不变 | 不写 partial attempt | 只恢复之前 accepted entries；partial text 不进 Context | ready | 否 | 无 partial 冒充 accepted |
| existing DB / exactly one Game | exact durable values | exact current materialization | 正常 rehydrate | `ready/resumed` | 否 | 无 |
| existing DB / zero Game rows | 无 Game | 无可绑定 Conversation | 不建立空 Domain product session；send blocked | startup/resume failure | 否 | 不 mint replacement |
| corrupt/unreadable DB | 原文件保留 | unknown，不猜测 | 不 rehydrate；send blocked | storage/startup failure | 否 | 不创建空库替代 |
| unsupported schema / failed migration | 原 version/data 保留 | migration 写入全部 rollback | 不进入 ready | schema/startup failure | 否 | 不升级一半、不 fresh fallback |
| existing DB / >1 Game rows | 所有 rows 保留，不猜 current | 不选择任一 materialization | 不 rehydrate；send blocked | ambiguous current Game | 否 | 不做 picker、不猜最近 |

## 3. Migration 与 durable ordering 不变量

- schema v1→v2 只新增 current `conversation_materializations`；不改 G3-02 Game/World/Timeline tables、fingerprint 或 historical snapshot。
- migration 在单一 SQLite transaction 内完成：create table → 为现有 Games seed `[]` → version 1→2；任何中段失败 rollback 后仍是可用 v1。
- accepted Conversation 只保存有序 `player_text + gm_text`；streaming/cancelled/failed/provider/context/UI material 永不写入。
- Runtime 在 Provider completed 后读取 Conversation non-mutating candidate，先 durable COMMIT，再调用 Domain accept；write failure 调用 Domain fail，不向 UI 发布 completed success。
- reopen 从 durable accepted truth 构造新 Turn objects；Context Assembly 每次从 Domain projection 重建，并保持 `game_context_text=""`，不把 opaque World JSON 倾倒到 prompt。
- production locator 只接受一个集中 DB path；existing zero/multi/corrupt/schema failure 均 fail-loud，只有文件真实不存在时允许创建一个 Game。
