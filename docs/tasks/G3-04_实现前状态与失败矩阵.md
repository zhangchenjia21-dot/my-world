# G3-04 实现前状态与失败矩阵

本矩阵在 schema v3 与 Save/Restore 产品路径编码前冻结语义。它只覆盖玩家明确创建 Save Point、明确 Load/Restore、恢复后的 Context rebuild；不建立 G3-05 自动恢复点、Timeline browser、任意 Turn rewind、Save manager 或 branch semantics。

## 1. 职责与原子边界

| 职责 | Owner / 层级 | 不变量 |
|---|---|---|
| accepted Turn 合法性、顺序、non-mutating validation、in-memory replacement | Conversation Domain | Persistence 不复制 Conversation 业务规则；validation 不修改 live truth |
| `save_points` representation、v2→v3 migration、coherent Save read、atomic Restore transaction | Persistence `L2_流程层` | Save 只引用 immutable Timeline anchor 并携带 Conversation recovery material；Restore 全成或全败 |
| create/list/get/restore Save DTO | Persistence `L3_外交层` | 不泄露 SQLite connection/row object，不把 Save name 当 identity |
| generation gate、COMMIT 后 memory apply、reopen-required blocking state | Current Game Runtime | active generation 禁止 Save/Load；durable COMMIT 先于 memory/UI 切换 |
| Save/Load request、explicit confirmation、Narrative full redraw | UI / Application Shell | UI 只是 projection/request surface，不保存第二份 history，不显示 Timeline/SQLite 工程细节 |
| Provider messages | Context Assembly | 只从 restored Conversation projection 重建；最近 12 个完整 Turn；不读取 stored prompt/context |

Restore durable transaction 固定为：解析 Save → 校验 Conversation snapshot → 读取同 Game immutable Timeline snapshot → 更新 current World → 更新 active head → 替换 current accepted Conversation → COMMIT。任何一步失败都 rollback；COMMIT 后才允许 Runtime、Conversation 与 UI 切换。

## 2. Save State / Failure Matrix

表中“当前三元组”指 durable active head / current World / current accepted Conversation。

| 场景 | Durable 当前三元组 | In-memory Conversation / Context | Save / Timeline 变化 | 玩家结果与 retry | fallback / half-state / future leak |
|---|---|---|---|---|---|
| empty accepted Conversation | 全部保持；Conversation 为 `[]` | memory 仍空；Context 仍仅 system/current attempt | 新增 immutable Save，anchor=当前 head；Timeline 不变 | 保存成功，可稍后明确读取 | 无 |
| normal accepted history | 全部 exact 保持 | memory/Context 不变 | Save snapshot exact round-trip 全部 accepted pairs | 保存成功 | 无 |
| >12 accepted Turns | durable 全量历史保持 | memory 全量；Context 仍仅 recent 12 | Save 保存全量 accepted history，不截断；Timeline 不变 | 保存成功 | 无；bounded Context 不等于 starved Save |
| one/multiple World mutations 后保存 | 当前 H/W/C 保持 | 不变 | transaction 内读取同一 durable moment 的 active head + Conversation；只新增 Save | 保存成功 | 无 mixed head/Conversation capture |
| active Provider generation | 全部保持 | streaming attempt 保持；不参与 Save | 无新增 Save/Timeline | controls disabled，要求取消或等待后重试 | partial draft 不会冒充 accepted truth |
| empty display name | 全部保持 | 不变 | 无新增 Save | `invalid_input`，玩家可修改名称重试 | 无 |
| Unicode display name | 全部保持 | 不变 | 新 Save；名称 exact round-trip | 成功并按原文显示 | 无 |
| duplicate display name | 全部保持 | 不变 | 允许创建不同 stable `save_id` 的独立 Save | 成功；UI selection 以 save_id 绑定 | 名称不承担 identity，无 overwrite |
| SQLite insert/commit failure | 全部保持 | 不变 | transaction rollback；无 partial Save，Timeline 不变 | fail-loud、retryable，不显示假成功 | 无 |
| existing v2 DB → v3 | 原 Game/head/World/Conversation exact 保持 | reopen 后 exact rehydrate / rebuild Context | transaction additive 创建空 `save_points`，version→3 | 正常打开 | 无 |
| v2→v3 intentional mid-migration failure | v2 全部保持 | startup 不进入 ready | table/version changes rollback，仍为可打开 v2 | schema/storage failure；修复后重试 | 不 fresh fallback、不半升级 |

## 3. Load / Restore State / Failure Matrix

| 场景 | Durable active head / World / Conversation | In-memory Conversation / Context | Save / Timeline 变化 | 玩家结果与 rollback/retry | fallback / half-restore / future leak |
|---|---|---|---|---|---|
| Load 指向当前 H/C 的 Save | COMMIT 后仍 exact current H/W/C | validation 后 full replace/redraw；Context 重建为相同 truth | Save 保留；Timeline 全部不变 | 明确确认后成功 | 无 duplicate/patch drift |
| old Save + Conversation-only future | 原子恢复目标 H/W/Csave | memory exact Csave；未来 Turns 从 full redraw 消失；Context 无未来 | Save 保留；Timeline 不变 | 成功，可从旧点继续 | 无 future-memory leak |
| old Save + World/Conversation future | 原子恢复 Hsave/Wsave/Csave | memory exact Csave；Context 从恢复 truth 重建 | later Timeline nodes 保留且 immutable；所有 Save 保留 | 成功 | 无 half-old/half-new |
| >12 saved Turns | durable 恢复完整 Csave | memory 全量；Context 仅最后 12 对 + current player once/last | 不变 | 成功 | 无历史截断或未来泄漏 |
| active Provider generation | 全部保持旧 current | streaming attempt 保持，不触发 restore/callback race | 不变 | controls disabled；取消/等待后可重试 | 无 silent Load、无 partial accepted |
| missing save_id | 全部保持 | memory/Context/UI history 保持 | 不变 | `not_found`，显示可读错误，可刷新列表 | 无 fresh fallback |
| missing/corrupt Timeline anchor | 全部保持 | memory/Context/UI history 保持 | 不变 | fail-loud storage/integrity error | 不创建空 Game，不猜 World |
| invalid Conversation snapshot | validation 在写前失败；全部保持 | live Conversation 未修改，Context/UI 保持 | 不变 | stable validation/storage error | 无 Persistence 自行“修正”或部分恢复 |
| SQL failure after World write before head/Conversation | transaction rollback，旧 H/W/C 全保持 | memory/Context/UI 保持旧 current | Save/Timeline 不变 | fail-loud，可重试 | 无 half-restore |
| SQL failure after head write before Conversation | transaction rollback，旧 H/W/C 全保持 | memory/Context/UI 保持旧 current | Save/Timeline 不变 | fail-loud，可重试 | 无 half-restore |
| COMMIT 后进程死于 memory/UI apply 前 | DB 已完整为 Hsave/Wsave/Csave | 进程内状态不再可信且不可继续；重开从 durable truth rehydrate | Save/Timeline 保留 | exact process restart 后恢复成功 | 无 shutdown flush 依赖；旧 memory 不继续游戏 |
| normal reopen after Restore | exact Hsave/Wsave/Csave | rehydrate exact；Context rebuild | 不变 | 正常 resumed；后续新 Turn 可 durable | 无 fallback |
| future marker `FUTURE_ONLY_SECRET_G304` 在 Restore 前存在 | 原子恢复到不含 marker 的 Csave/Wsave | accepted projection、assembled messages 均不含 marker；current player once/last | future Timeline node 保留，但不进入 Context；Save 保留 | 成功并自然继续 | blocking assertion：任何 marker 泄漏即 FAIL |

## 4. 实现与验证约束

- `save_id` 是 stable identity；`display_name` 只是玩家可读标签，Save 创建后 immutable。
- Save transaction 自己读取 durable current head 与 current Conversation，避免 UI/in-memory 竞态；Save 不写 current World/head/Conversation/Timeline。
- Conversation 先 non-mutating validate candidate；只有 Restore durable COMMIT 成功后才 replace live accepted entries。
- COMMIT 后若 memory apply 出现理论上不应发生的失败，Runtime 进入 reopen-required blocking state，禁止继续发送新 Turn。
- UI 成功 Restore 后从 Domain projection 完整重绘 Narrative；失败时不 patch、不清空旧 UI。
- 所有 destructive/failure-injection DB 只能使用经绝对路径校验的 `build/g3_04_*` 隔离路径。
- 不持久化 Context/Prompt/Provider messages，不向 Prompt 倾倒 opaque World JSON，不添加 `max_tokens` 或 Narrative 长度限制。
