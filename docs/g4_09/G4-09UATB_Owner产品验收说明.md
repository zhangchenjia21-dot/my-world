# G4-09UATB Owner 产品验收说明

本轮只判断一件事：**“判定与检定：公开 d20”是否为实际游玩增加了值得保留的乐趣。**

## 验收路线

1. 双击 `run-game.cmd` 启动游戏。
2. 选择【新游戏】，使用以下组合：
   - World：`汉末三国：天下未定`
   - Entry：`208 / 赤壁前夕`
   - Player：`刘备`
   - Guaranteed NPC（可选）：`孙权`
   - Expansion：`判定与检定：公开 d20`
3. 在 Review 页面确认已明确列出 `判定与检定：公开 d20`，然后创建游戏。
4. 等待真实 DeepSeek 第一幕完成。
5. 执行一个结果确有不确定性、失败也确有代价的冒险行动。
6. 确认界面出现公开 d20 判定卡，并确认随后 GM 叙事尊重卡片显示的成功或失败结果。
7. 再执行一个普通、无风险或无需随机决定的行动，确认不会仅因启用了 Expansion 就出现骰卡。
8. 保存游戏，返回主菜单，再选择【继续游戏】。
9. 确认打开的是同一局，历史叙事和先前的判定卡仍然存在且结果未改变。
10. 根据实际体验判断：公开 d20 是否增加了有意义的紧张感、清晰度或玩法价值，而不只是“技术上能运行”。

## 返回格式

如果认可本轮产品体验，只回复：

```text
PASS
```

如果不认可或遇到问题，回复：

```text
FAIL
<哪里不好玩、哪里不自然，或具体哪里坏了>
```
